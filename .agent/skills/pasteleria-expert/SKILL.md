# Pastelería Expert Skill

## Descripción
Esta skill se activa automáticamente cuando el usuario pide lógica de negocio, reglas o cálculos sobre recetas, ingredientes, mermas o inventario de la pastelería.

## Reglas de Negocio
1. El stock nunca puede ser negativo.
2. La merma genera alerta si supera el 15% de la producción.
3. Si la harina baja de 10kg, el estado cambia a REORDEN.
